# rl-snn-iot-edge
**RL-SNN-Edge: Reinforcement Learning-Based Optimization of Spiking Neural Networks for Resource-Constrained Edge/IoT Devices**

This project investigates hardware-aware optimization of Spiking Neural Networks (SNNs) for resource-constrained IoT edge devices.

The system consists of: DHT11 Sensor, ESP8266,  Raspberry Pi 3B, Jetson Nano 4GB,  SNN, RL Architecture Optimization
                   
## Edge Hardware

### Raspberry Pi 3B+

- Model: Raspberry Pi 3 Model B Plus Rev 1.3
- CPU cores: 4
- RAM: 1 GB
- Architecture: ARM64
- OS: Debian 12 (Bookworm)
- Python: 3.11.2
- Storage: 58 GB microSD

### NVIDIA Jetson Nano

- 4 GB RAM
- ARM-based edge computing platform

### IoT Sensor

- ESP8266
- DHT11 temperature/humidity sensor
